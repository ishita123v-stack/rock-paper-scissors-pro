# Rock, Paper, Scissors Pro 🎮

My second Python project! A text-based implementation of the classic Rock, Paper, Scissors game featuring a persistent scoreboard, input validation, and an interactive exit option.

## Features
- Smart input handling (ignores accidental spaces or capital letters).
- Real-time scoreboard.
- Randomized AI opponent using Python's `random` module.
